## [1.0.0] — Unreleased

### Added
- MATLAB implementation of Prandtl's lifting-line theory (`liftingline.m`)
- Python port of the lifting-line solver (`liftingline.py`)
- Geometry generation scripts: elliptic and rectangular wings
- Validation tests (CI) with 5 quality checks
- Validation report with comparison against classical theory
- LaTeX algorithm documentation
- GitHub Actions CI for Python, MATLAB (via Octave), and LaTeX compilation
- README, LICENSE, and changelog
